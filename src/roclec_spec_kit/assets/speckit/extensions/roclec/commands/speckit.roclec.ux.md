# Roclec UX

For the current spec, read `.roclec/project.toml`, `spec.md`, and the project's product and design guidance. Use this step only for components marked `user_facing = true`. Write `ux.md` with journeys, screen or view states, errors, accessibility, and links to the spec's AC IDs. Keep product-specific conventions in the project, not in this command. Do not change acceptance criteria without the user's approval.
