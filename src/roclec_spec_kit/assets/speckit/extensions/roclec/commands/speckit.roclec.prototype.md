# Roclec prototype

Read the current `spec.md`, `ux.md`, and project design guidance. For the bundled design pipeline, confirm the four pinned skills in `skills-lock.json` are installed with `roclec skills --restore` before starting. Use `ui-ux-pro-max` for direction, `frontend-design` to create HTML, `impeccable` for critique and polish, and `web-design-guidelines` for the final accessibility and interface review. A project may define another pipeline in its own instructions and lock file; do not silently skip a required step.

Create a clickable HTML prototype under `specs/<spec>/prototype/`. Cover the meaningful states and interactions in the UX spec. Show it to the user for review before treating the prototype as approved. The ready gate requires a prototype file but human approval remains a project workflow decision.
